## 💼 Featured Work

### 🤖 Hi Tech AI Sales Assistant

<a href="https://app.hitech-machinery.com/"><img src="https://img.shields.io/badge/Live%20App-app.hitech--machinery.com-0A66C2?style=for-the-badge" alt="Live app: app.hitech-machinery.com"></a>

An internal assistant on WhatsApp and web chat that answers sales reps' questions about machines in seconds, using retrieval-augmented generation (RAG) over 1,700+ catalogue records. It understands Roman Urdu and voice notes, and it also automates expense reporting, from a receipt photo all the way to a role-based approval.

<sub>Company project, co-developed. The app is an internal tool, so it opens at a staff sign-in page.</sub>
